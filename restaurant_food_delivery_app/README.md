# TasteCraft | Gourmet Food & Grocery Web App with WhatsApp & QR Ordering

A modern, high-conversion web application designed for restaurants, dark kitchens, cafes, and grocery stores. Features instant WhatsApp order formatting, interactive shopping cart, dine-in table QR code support, and zero third-party platform commissions.

---

## 🌟 Key Features

1. **Rich Product Catalog & Category Filtering:**
   - 6 categorized sections: Artisan Pizza, Gourmet Burgers, Japanese Sushi, Daily Fresh Grocery, Handcrafted Desserts & Drinks.
   - Real-time search with instant filtering.
   - Dietary badges (Chef Special, Organic, Vegan, Bestseller) and star ratings.

2. **Interactive Slide-Over Cart Drawer:**
   - Persistent `localStorage` item retention.
   - Instant quantity adjustments (+ / -).
   - Order mode switcher: **🛵 Home Delivery** or **🍽️ Dine-in Table Service**.
   - Subtotal, delivery fee, and dynamic total calculation.

3. **100% Direct WhatsApp Order Dispatch:**
   - Formats complete, professional digital receipts with emojis, unique Order ID, timestamps, customer address / table number, itemized totals, and delivery notes.
   - Generates direct `wa.me` links with zero intermediate server fees.

4. **Dynamic Table Stand QR Code System:**
   - Canvas-rendered vector QR codes for physical table tents.
   - Supports table URL parameters (`?table=03`) for instant seated ordering.
   - 1-click printable table stand view.

5. **Responsive & Mobile-First Design:**
   - Tailored HSL color palette, dark mode accents, glassmorphic header, and micro-animations.
   - Optimized for iOS Safari, Android Chrome, tablets, and desktop.

## 🚀 Quick Start (Local Run)

Simply double-click:
```bash
run_demo.bat
```
Or run:
```bash
python -m http.server 8080
```
Then navigate to `http://localhost:8080`.
